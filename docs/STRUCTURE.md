## 🔄 Mise à Jour de la Documentation

### Quand mettre à jour ?

- ✅ **Apprentissages** : Après chaque apprentissage significatif
- ✅ **Changelog** : Après chaque modification majeure
- ✅ **Guides** : Quand un processus change
- ✅ **Audit** : Après chaque audit

### Comment mettre à jour ?

1. Identifier le document concerné
2. Ajouter/modifier la section pertinente
3. Mettre à jour la date de dernière mise à jour
4. Vérifier les liens dans le README si nécessaire
