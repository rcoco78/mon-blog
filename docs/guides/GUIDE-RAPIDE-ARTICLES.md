# Guide Rapide : Créer un Article

## 🚀 Méthode Rapide (Recommandée)

### Option 1 : Script automatique

```bash
# Après une mission
npm run create-article "Scraping LinkedIn : Comment j'ai extrait 5000 profils" --type=mission

# Réflexion hebdomadaire
npm run create-article "Pourquoi j'ai arrêté de promettre des délais fixes" --type=weekly

# Article spontané
npm run create-article "Cette API que j'utilise maintenant partout" --type=spontaneous
```

Le script crée automatiquement dans Notion :
- ✅ La page avec le titre
- ✅ La date du jour
- ✅ Les tags appropriés
- ✅ La meta description
- ✅ Le template de contenu structuré

**Ensuite** : Tu édites dans Notion et publies. Le site se met à jour automatiquement.

---

### Option 2 : Manuel dans Notion

1. **Ouvre ta base Notion Blog**
2. **Nouvelle page** → Remplis :
   - **Title** : Titre accrocheur
   - **Date** : Date de publication
   - **Tags** : 3-5 tags (voir guide complet)
   - **Meta Description** : 150-160 caractères
3. **Écris le contenu** (voir template ci-dessous)
4. **Publie** → Le site se met à jour au prochain build

---

## 📋 Template Rapide (Copier-Coller)

### Après une mission :

```
# [Technique] : [Résultat]

[Intro : Hook personnel]
Exemple : "La semaine dernière, un client m'a demandé d'extraire 10 000 profils LinkedIn. En 2h, c'était fait."

## Le problème du client

[Description]

## Ma solution

[Approche]

## Le résultat

[Impact]

## Ce que j'ai appris

[Leçons]
```

**Tags** : `scraping`, `cas-d-usage`, `technique`, `mission`

---

### Réflexion hebdomadaire :

```
# [Sujet] : [Angle]

[Intro : Le déclic de la semaine]

## Pourquoi c'est important

[Contexte]

## Mon expérience

[Ce que j'ai vécu]

## Ce que ça change

[Impact]

## Question ouverte

[Invitation à réfléchir]
```

**Tags** : `réflexion`, `entrepreneuriat`, `processus`, `apprentissage`

---

### Spontané :

```
# [Sujet]

[Intro : Ce qui t'inspire]

## Le contexte

[Pourquoi maintenant]

## Mon point de vue

[Ta réflexion]

## Et toi ?

[Ouverture]
```

**Tags** : `introspection`, `réflexion`, `apprentissage`

---

## ✅ Checklist 2 min avant publication

- [ ] Titre accrocheur avec bénéfice
- [ ] Date = aujourd'hui
- [ ] 3-5 tags pertinents
- [ ] Meta description (150-160 caractères)
- [ ] Hook personnel en intro
- [ ] Structure claire (titres H2)
- [ ] Conclusion avec ouverture

---

## 💡 Rappel

**L'objectif** : Partager, pas vendre.
**Le ton** : Authentique, personnel, utile.
**La fréquence** : 1-2 articles par semaine, sans pression.
