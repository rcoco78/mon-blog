## 🎯 Quick Start

### Pour optimiser une nouvelle page
1. Lire [Apprentissages SEO](./APPRENTISSAGES-SEO.md) pour comprendre les principes
2. Consulter [Guide SEO Principal](../03-SEO.md) pour la configuration
3. Suivre la checklist dans [Apprentissages SEO](./APPRENTISSAGES-SEO.md)

### Pour créer un article de blog
1. **Lire en premier** : [Guide Création Article Blog](./GUIDE-CREATION-ARTICLE-BLOG.md) ⭐
2. Suivre la checklist complète par phase
3. Consulter [SEO Articles de Blog](./SEO-ARTICLES-BLOG.md) pour les détails techniques
4. Valider avec Google Rich Results Test après publication
